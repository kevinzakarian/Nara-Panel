# Verification — NARA 0.14.0 · 2026-10-18

- **182 frontend tests passed without skips.** Coverage includes all pinned rule/action fields, typed scalar/list round trips, searchable multiple selection, custom identities/numeric DNS query types, clearing values, action remounting, all three palettes, device preference changes, saved appearance controls and account/live-connection badge distinctions. Every traffic/DNS action and logical forms are checked with the real 1.14.3 core.
- **348 Python tests passed without skips** in the final complete run (459.969 seconds), using the real compatible core and official Caddy 2.4.6/2.6.2 binaries. An initial VMess fixture timeout did not recur in its isolated rerun or final full run. A separate build-runner test exposed its 250 ms interpreter-startup race on a busy host; its fixture budget is now one second while its child still sleeps for ten seconds, preserving real timeout/retry coverage.
- The new live presence test opens an authenticated VLESS traffic connection, checks its identity/count through the official private API, rejects an invalid secret, closes the flow and checks that it disappears. Decoder tests exclude closed and unmanaged identities. Accounting, quota enforcement, metadata changes without core restart, rollback and portable operations retain their full regression coverage.
- **All four native Linux jobs passed** on implementation commit `1e3be9e`: Linux amd64 and arm64 without Go/Git, a real systemd upgrade with a live WAL database, and SSH migration to a disposable destination. [GitHub Actions run](https://github.com/kevinzakarian/Nara-Panel/actions/runs/39157080182). The final evidence-only commit adds this report and screenshots; implementation files are unchanged.

Browser verification used disposable loopback services and synthetic accounts. All six skin/mode combinations were saved and rendered in the real panel. A live account displayed **Online · 1 connection**, independently of its Active eligibility. Searchable inbound/account selection and route-target saving were exercised. Settings uses one Save action, section shortcuts and immediate appearance preview. The update-available banner in screenshots is simulated fixture data, not a claim about a later release. At the 1280 px browser width, both version components and their contents were measured inside their separate bounds with no overlap. No production server, customer account or external notification was modified.
